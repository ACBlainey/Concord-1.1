# Core Wrapper Architecture

**Project:** The Concord V1.1  
**Status:** ACTIVE DEVELOPMENT / NOT CANONICAL

This folder contains the current development papers for the Concord's wrapper and interoperability architecture.

## Fractal Interoperability Paper Lineage

Two versions of **From Civilisational Wrappers to Fractal Interoperability** are intentionally retained.

### Earlier baseline version

**From Civilisational Wrappers to Fractal Interoperability — Concord Wrappers Across Civilisations, Nations, Regions and Local Governance.md**

This is the earlier baseline paper. It established the scale-independent wrapper concept, internal federal and local-government applications, anti-centralisation significance, sovereignty-neutral interfaces, Tacit Recognition Drift, non-inference architecture, and the general wrapper data model.

It is retained because it contains concrete examples and framing that were generalised or reorganised in the later expanded version, including explicit U.S. federal-law examples, the UK-council framing, and the earlier Special-Jurisdiction profile naming free zones, autonomous areas, special administrative areas and disputed territories.

This version should therefore be treated as **developmental provenance and supporting detail**, not as the most current statement of the architecture.

### Expanded successor version

**From Civilisational Wrappers to Fractal Interoperability — Concord Wrappers Across Civilisations, Nations, Regions, Special Jurisdictions and Local Governance.md**

This is the current expanded successor. It preserves the main architecture of the baseline paper while extending it to Safe Spaces, bounded legal variation, externalities, functional decomposition, functional trust, Functionally Bounded Summits, Functional Failure Containment, deliberate scope expansion, and more detailed failure classification.

Where the two papers differ in architectural development, the expanded paper should be read as the current working formulation. The baseline remains available to preserve provenance, examples and earlier formulation detail.
